# go/

- `gen/` — generated by `dagr build` (module `otlptraces`): lazy accessors, arena,
  serializer, the `otlptracesdirect` value-tree builder, and the `spanlog` DataSink.
  Not committed.
- `internal/seed/` — the deterministic 500-span batch, a port of `otlp_seed()` from the
  Dagr repo's `benchmarks/proto_vs_dagr` (same LCG, same draw order).
- `internal/fixture/` — that seed materialised as `ptrace.Traces`.
- `pdatabridge/` — `pdata.Traces` ⇄ Dagr bytes. Encode via the direct builder; decode
  exists for compatibility and is the slow path by construction. Attribute values recurse
  through Slice and Map (`array_value` / `kvlist_value`); the decoder bounds its own
  recursion at `MaxValueDepth`.
- `bench/` — the measurements in the top-level README.
- `spool/` — the spool file behind both components: create or resume, append, read
  forward or newest-first, and decide whether the tail is intact. Nothing here parses a
  record body; framing is walked with the generated reader and the runtime's varint
  primitives.
- `exporter/` — `dagrfileexporter`, a collector traces exporter. `ConsumeTraces` →
  direct builder → one appended record. Implements `exporter.Traces` directly: the spool
  *is* the queue, so there is deliberately no `exporterhelper` queue in front of it.
- `receiver/` — `dagrfilereceiver`, the spool back into an unmodified pipeline. The slow
  path by construction (it materialises), and documented as such.
- `store/` — the query surface over a spool (spec/38 §6.2, §6.3): `Query` reads spans
  newest-first as lazy handles and reports what the walk actually cost, `Ring` bounds the
  spool by compacting from the tail without reading what it drops, and `Sampler` is a
  tail sampler that keeps one flat summary per trace instead of every span of every
  undecided trace.
- `cmd/otlpdagrctl/` — the round-trip harness `ocb/roundtrip.sh` drives: `send` a batch
  over OTLP/HTTP, `spool` to report and check a spool, `verify` a dump against what was
  sent.

```
go test ./...                                       # every gate
go test ./bench -bench . -benchmem -benchtime 500x  # the read/encode numbers
go test ./exporter -bench ConsumeTraces -benchtime 2s
go test ./store -bench . -benchtime 2s              # crash ring + lazy vs pdata decisions
../ocb/roundtrip.sh                                 # through a real ocb-built collector
```
