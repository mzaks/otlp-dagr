# go/

- `gen/` — generated by `dagr build` (module `otlptraces`): lazy accessors, arena,
  serializer, and the `otlptracesdirect` value-tree builder. Not committed.
- `internal/seed/` — the deterministic 500-span batch, a port of `otlp_seed()` from the
  Dagr repo's `benchmarks/proto_vs_dagr` (same LCG, same draw order).
- `internal/fixture/` — that seed materialised as `ptrace.Traces`.
- `pdatabridge/` — `pdata.Traces` ⇄ Dagr bytes. Encode via the direct builder; decode
  exists for compatibility and is the slow path by construction.
- `bench/` — the measurements in the top-level README.

```
go test ./bench -run Test -v                        # correctness gates
go test ./bench -bench . -benchmem -benchtime 500x  # the numbers
```
